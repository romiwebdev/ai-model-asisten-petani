# 🌾 Young Farmer Assistant (AI Chatbot)

This project is a Gemini-based AI chatbot by Google, specifically designed to help young or beginner farmers. With a web interface built on [Streamlit](https://streamlit.io), anyone can ask questions about agriculture and receive automatic guidance from the AI.

## 🧠 Main Features
- AI answers from the Gemini model (1.5-pro)
- Language that's easy for beginner farmers to understand
- No installation needed — just open it from the web
- Accessible from a phone or laptop

## 🚀 How to Run (on Streamlit Cloud)

1. **Create a GitHub account** and upload the `app.py` file
2. **Visit [streamlit.io/cloud](https://streamlit.io/cloud)** and log in
3. Click **"New app"** and select the repo containing `app.py`
4. Enter the Secrets:
    ```
    GEMINI_API_KEY = "YOUR_API_KEY"
    ```
5. Click Deploy

✅ The app is now accessible to anyone via a public link such as:
```
https://asisten-petani.streamlit.app
```
